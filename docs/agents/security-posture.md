# Security posture

Stakes level: standard — a self-hosted, open-source tool: Members sign in to the dashboard, public Widget and API endpoints receive Feedback carrying Authors' personal data and Captures, and the Instance stores third-party credentials for its Judge and Destinations; no payments, no multi-tenancy.

## Accepted compromises

| Control                   | Compromise                                                                                                                                                                                                                       | Why                                                                                                         | Revisit when                                          |
| ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- | ----------------------------------------------------- |
| Outbound URL guard        | Member-configured URLs (webhooks, Alert destination, dashboard-chosen Judge) may reach hosts the operator lists in `NUDGE_OUTBOUND_ALLOWED_HOSTS`; `0.0.0.0/0,::/0` disables the guard. The `NUDGE_JUDGE_*` Judge is not guarded | Self-hosters legitimately send webhooks to LAN or compose hosts; the operator, not a Member, opens the hole | Members become less trusted than the operator (roles) |
| Per-Project Widget budget | Anyone holding the public key can spend the per-Project Widget budget (600/min per replica) and the Judge spend behind it                                                                                                        | Public-key ingestion by design (D8); bounded by per-IP and per-Project limits                               | Abuse is reported, or Judge spend caps land           |
| Triage is not trust       | An Author can steer Triage type and severity (model-based guardrail only) and so reach Destinations filtered on severity                                                                                                         | Routing convenience, not an authorization boundary; documented in SECURITY.md                               | Destinations start carrying privileged actions        |
| Dev-only advisories       | esbuild advisories via drizzle-kit (no fix released) and tsup 8 (fix needs tsup 9) stay open                                                                                                                                     | Development tooling only, never in the images                                                               | A fixed drizzle-kit ships, or tsup 9 is adopted       |
| Linear escaping           | Linear descriptions rely on Linear's renderer honouring CommonMark backslash escapes                                                                                                                                             | Verified locally with markdown-it only; Linear's renderer is outside the repository                         | A rendering bypass is reported                        |
